# Exoscale Infrastructure Templates

This repository contains infrastructure templates and reference architectures for deploying common customer setups on Exoscale.

## 🏗️ Available Templates

### [Exoscale Zero Trust Multi-Organization Network](./exoscale-zero-trust-multi-org/)

A complete Zero Trust network architecture solution for deploying multi-organization networks on Exoscale with centralized security control. See the [template documentation](./exoscale-zero-trust-multi-org/) for detailed information.

## 🌿 Quick Start

Each template includes complete deployment configurations, testing guides, and detailed documentation.

## 🤝 Contributing

When adding new templates:

1. **Create descriptive folder names**: `exoscale-[use-case]-[architecture]`
2. **Include complete documentation**: README, ARCHITECTURE, TESTING-GUIDE
3. **Provide test environments**: Always include a test setup
4. **Use generic naming**: Avoid specific customer names or data in code and documentation
